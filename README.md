Solving #B1 KSN-P Informatika 2021
(tlx.toki.id)

Berisi kode program dalam C++ berisi jawaban soal KSN-P bagian B (pemrograman)
tahun 2021 nomor B1 yang bisa diakes pada https://tlx.toki.id/submissions/3549374 

Anda dapat menjalankan dengan cara berikut.
1. Clone repository
	git clone https://github.com/stepanusimnuel/KSN-P-2021-B1.git
	cd KSN-P-2021-B1
2. Pastikan compiler C++ sudah terinstall.
	cek dengan
	g++ --version
	
	compile file
	g++ main.cpp -o main
3. Jalankan program
	main.exe atau ./main
4. Masukkan input N, A, B yaitu banyaknya buah apel, berat apel A,
dan berat apel B berturut-turut.
	
Anda juga dapat menyalin kode saya dan menempatkannya 
pada online c++ compiler seperti link di bawah ini.
